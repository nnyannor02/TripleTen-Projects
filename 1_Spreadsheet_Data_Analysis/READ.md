# Spreadsheet Data Analysis

This project focuses on exploring and analyzing a multi-sheet dataset using Excel. The goal was to clean raw data, apply formulas, build pivot tables, and summarize key insights that describe performance patterns across different variables.

## Contents
- **Spreadsheet Data Analysis_Project.xlsx**
  - Raw data
  - Cleaned data
  - Pivot tables
  - Summary calculations

## What This Project Covers
- Data cleaning and formatting  
- Use of functions (LOOKUPs, conditional logic, date calculations)  
- Pivot table analysis  
- Comparing groups and identifying patterns  
- Summarizing insights in a clear, structured way  

This project demonstrates foundational analytical skills using Excel, including organization, interpretation, and reporting.
