# Return Rates Dashboard (Tableau)

This dashboard analyzes return trends in the Superstore dataset. It explores return rates by category, state, customer, and month to uncover drivers of product returns and operational improvement opportunities.

## Tableau Dashboard
🔗 https://public.tableau.com/app/profile/nana.serwaah.nyannor/viz/ReturnRates_nnyannor/ReturnRatebyCustomer

## Folder Contents
- `Dashboard_Return Rates_nnyannor.zip`  
  (Packaged Tableau file and dashboard export)
- Optional: screenshots folder
- README.md (this file)

## What This Project Covers
- Return rate patterns across categories
- Geographic return differences by state
- Month-to-month return fluctuations
- Customers with high return behavior
- Visual storytelling using Tableau

## Tools Used
- Tableau Public  
- Superstore dataset

This project demonstrates data storytelling and visual analysis through interactive dashboards.
