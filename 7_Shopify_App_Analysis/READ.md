# Shopify App Analysis (Power BI)

This project analyzes the Shopify App Store ecosystem using Power BI to explore app performance, ratings, and developer responsiveness. The analysis is structured into three sections:

---

## 🧩 Part 1: App Landscape
- Count of total apps  
- Trends in reviews over time  
- Relationship between review count and average rating  
- Key insights about the Shopify marketplace  

---

## 🧩 Part 2: Reviews Analysis
- Created custom metrics:
  - **helpful_reviews** = rating * (1 + helpful_count)
  - **developer_answered** = whether a developer responded  
- Scatterplots comparing ratings and responsiveness  
- Insights into review quality and developer engagement  

---

## 🧩 Part 3: Developer Analysis
- Relationship between apps and developers  
- Ranking developers by average helpful review score  
- Evaluating developer responsiveness  
- Insight: **FireApps** had the highest helpful_reviews score  

---

## 🗂️ Contents  
- Screenshots of each page  
- Video walkthrough  
- Summary of insights and recommendations  

This project demonstrates Power BI modeling, custom DAX metrics, data storytelling, and insight communication.
