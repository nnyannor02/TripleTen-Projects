# Shopify App Analysis (Power BI)

Power BI project video walkthrough analyzing the Shopify App Store ecosystem using app, category, and review data.  
Key analyses include:

- App landscape metrics  
- Review trends and rating patterns  
- Custom calculated metrics (helpful_reviews, developer_answered)  
- Developer responsiveness  
- Identification of top-performing developers  

This project demonstrates data modeling, DAX, dashboard visualization, and analytical storytelling.
