# TripleTen-Projects
### A collection of projects completed during the TripleTen Business Intelligence Analyst Program, including analytics, dashboards, modeling, and Power BI work.
---

## Table of Contents

| Project # | Project Title | Description |
|----------:|---------------|-------------|
| 1 | Spreadsheet Data Analysis | Excel-based analysis using formulas, pivot tables, and data cleaning to identify trends and summarize findings from raw data. |
| 2 | Return Rates Dashboard (Tableau) | Interactive Tableau dashboard analyzing Superstore product return rates by category, month, and state to identify key trends and improvement opportunities. |
| 3 | Superstore Advertising Analysis Project (Tableau) | Tableau analysis identifying the best state–month combinations for advertising, based on Superstore average profit performance. |
| 4 | Report-Based Analytics Project | Structured analytical report summarizing business trends, insights, and recommendations using multi-step analysis techniques. |
| 5 | Business Analytics Project 3 | Advanced Excel analytics project examining conversion funnels, cohort behavior, retention metrics, and customer lifecycle trends. |
| 6 | Job Search Strategy | Career development project focusing on resume refinement, job search structure, professional branding, and long-term career goals. |
| 7 | Shopify App Analysis (Power BI) | Power BI dashboard analyzing Shopify App Store data, including app trends, review patterns, developer responsiveness, and performance factors. |

Each project folder includes:
- Source files (Excel, Power BI, PDFs)
- A project-specific README summarizing the work
- Visuals, dashboards, or reports where applicable
